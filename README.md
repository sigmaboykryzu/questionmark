## 🎯 FEATURES

### Daily Challenges (8 Total)
1. **Quick Thinker** - Win 3 sequences → 5 SP
2. **Accuracy Master** - Win 5 sequences → 8 SP
3. **SP+ Collector** - Earn 3 SP+ → 10 SP
4. **SPx Collector** - Earn 2 SPx → 15 SP
5. **SP^ Collector** - Earn 1 SP^ → 25 SP
6. **Grinding Session** - Roll 50 times → 12 SP
7. **Perfect Series** - Win 3 in a row → 20 SP
8. **Long String Master** - Win with 25+ chars → 18 SP

### Game Modes
- **Classic** - Standard gameplay (1.0x multiplier)
- **Speed Run** - Complete 10 wins as fast as possible (1.5x)
- **Hardcore** - One loss and it's game over (2.0x)

### Tournaments
- **Weekly** - 5 rounds, 50 SP prize
- **Monthly** - 10 rounds, 200 SP prize

### Equipment System
**Gauntlets:**
- Iron Gauntlet (3 SP) - Reduce rolls by 1
- Steel Gauntlet (1 SP+) - +3 bonus rolls
- Silver Gauntlet (1 SPx) - +10% accuracy
- Gold Gauntlet (2 SPx) - +25% SP gained
- Obsidian Gauntlet (1 SP^) - Double SP earned

**Devices:**
- Basic Device (2 SP) - 1 free reroll per win
- Analysis Device (1 SP+) - See 1 extra property
- Fortune Device (2 SP+) - +15% luck in rolls
- Mastery Device (1 SPx) - 30% faster reveals
- Infinity Device (1 SP^) - See all target properties

## 🛠️ TROUBLESHOOTING

### Game won't start?
1. Make sure Python 3.9+ is installed
2. Try: `python questionmark.py`
3. Check for error messages

### Missing modules?
```bash
pip install -r requirements.txt
```

### Sound not working?
- Sound system gracefully degrades if audio unavailable
- Game works fine in silent mode
